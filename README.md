# AutoClicker

Небольшой автокликер на Python с графическим интерфейсом Tkinter.

## Возможности

- Автоматические нажатия левой кнопкой мыши (ЛКМ).
- Настройка интервала между кликами: от `0.01` до `3600` секунд.
- Настройка смещения курсора по осям X и Y относительно позиции мыши в момент запуска.
- Цикл работы: перемещение к точке со смещением → клик → возврат в исходную точку → клик.
- Остановка кнопкой **«Стоп»** или клавишей **Left Shift** (левый Shift).
- При остановке курсор возвращается в исходную позицию.

Положительное смещение X перемещает курсор вправо, отрицательное — влево. Положительное смещение Y перемещает курсор вниз, отрицательное — вверх. Смещение задаётся в целых пикселях.

## Запуск из исходного кода

Требуется Windows и Python 3.10 или новее.

1. Скачайте или клонируйте проект и откройте папку с файлом `autoclicker.py`.
2. Установите зависимость:

   ```bash
   py -m pip install pynput
   ```

3. Запустите приложение:

   ```bash
   py autoclicker.py
   ```

## Самостоятельная сборка в EXE

Для сборки используется [PyInstaller](https://pyinstaller.org/).

1. Установите необходимые пакеты:

   ```bash
   py -m pip install pynput pyinstaller
   ```

2. Откройте терминал в папке проекта и выполните команду:

   ```bash
   py -m PyInstaller --noconfirm --clean --onefile --windowed --name AutoClicker --collect-all pynput autoclicker.py
   ```

3. После завершения сборки готовый файл появится здесь:

   ```text
   dist/AutoClicker.exe
   ```

Параметр `--onefile` создаёт один EXE-файл, а `--windowed` отключает отдельное консольное окно. Для сборки Windows-версии запускайте PyInstaller в Windows.

## Управление

1. Укажите интервал между кликами в секундах.
2. Задайте смещение X и Y. Чтобы кликать в одной точке, оставьте оба значения равными `0`.
3. Наведите курсор на исходную позицию и нажмите **«Старт»**.
4. Для остановки нажмите **Left Shift** или кнопку **«Стоп»**.
